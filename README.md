# 1930.dev Homebrew tap

Casks for the apps built at [1930.dev](https://1930.dev).

```sh
brew install --cask 1930-dev/tap/mou-sugu
```

The cask files here are bumped automatically by each app's release workflow.
Do not edit `version` or `sha256` by hand — a manual bump will conflict with
the next automated one.
